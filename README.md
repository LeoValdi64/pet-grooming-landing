# Pawfect Grooming 🐾

Professional pet grooming landing page with a modern, warm design.

## 🔗 Live Demo

**Production URL:** [https://pet-grooming-landing.vercel.app](https://pet-grooming-landing.vercel.app)

## ✨ Features

- **Hero Section** - Eye-catching gradient hero with paw pattern background and CTA
- **Services Grid** - 6 grooming services with icons, descriptions, and pricing
- **Trust Badges** - 4 reasons to choose: Certified Groomers, Cage-Free, Natural Products, 10+ Years
- **Pricing Cards** - 3-tier pricing (Basic, Premium, Luxury) with feature lists
- **Gallery Section** - Before & After transformation placeholders
- **Testimonials** - 3 customer reviews with pet names and ratings
- **Booking CTA** - Prominent call-to-action with phone number and scheduling button
- **Footer** - Business hours, contact info, and social links

## 🎨 Design

- **Primary Color:** Teal (#0d9488)
- **Accent Color:** Coral/Orange (#f97316)
- **Background:** Cream (#fefce8)
- Modern, professional yet warm and welcoming
- Fully responsive mobile-first design
- Smooth hover animations

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Deploy:** Vercel
